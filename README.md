**## AWS Services**



**AWS S3 is used as the cloud storage service for storing uploaded files.**



**## How It Works**



**1. User selects a file from the React frontend.**

**2. The file is sent to the Node.js backend.**

**3. The backend uploads the file to an AWS S3 bucket.**

**4. Stored files are retrieved through the backend API.**

**5. Users can download files from the application.**
